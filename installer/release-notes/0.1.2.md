**Moly 0.1.2.** The desktop app, the browser extension and the Android app now carry the same version number.

**What is new for the computer**
- **Sign-in.** Moly now asks who is using it. The first start makes your profile (a name and a password); after that you choose your name and type the password each time the browser has been closed. Another person who uses the computer makes a profile of their own, with its own conversations, people, settings and AI key. Conversations that an earlier version kept on the computer become those of the first profile you make. A recovery code is shown once when a profile is made: it is the only way back in after a forgotten password. Settings has "Change password". After five wrong passwords in a row Moly makes you wait a few minutes. The password keeps other people of the computer out of your conversations in Moly; people who use the same computer account can still open its files, so for real separation use a separate computer account for each person.
- **Install and update from the extension.** The "Download latest version" button downloads the installer for your system and opens it. Settings, "Moly app" shows the installed version and offers "Update to ..." when a newer one exists. The browser asks once for the optional downloads permission when you press the button; if you refuse, an ordinary download link is used.
- **Double-click installers.** Linux: a `.deb` package (Debian, Ubuntu, Mint; x86-64) for all users of the computer. Mac: a `.pkg`. Windows: the setup program as before. The one-line command for Linux and Mac still works and also serves ARM computers.
- **When the app is removed while Moly is open,** Moly shows the install screen by itself, with the steps and a button, instead of "could not start". Settings, "Remove Moly" and a page that your browser opens when you remove the extension explain how to remove the app too.
- **Your language.** Questions, refusals and the other texts Moly writes follow the language you write in. The interface itself is still English.
- **Fewer wrong assumptions.** Replies state only what you told Moly; Moly no longer addresses you by the name of a person you mention.
- Many old analysis steps were removed. The extension no longer writes message text to the browser console.

**Install:** Windows: download and run `moly-setup-0.1.2.exe`. Linux: open `moly_0.1.2_amd64.deb` with your software installer, or run `curl -fsSL https://nireus79.github.io/Moly/install.sh | sh`. Mac: open `moly-0.1.2-macos-universal.pkg`. Then install the extension from your browser's store and press "Check again". Step by step: [INSTALL.md](https://github.com/Nireus79/Moly/blob/master/INSTALL.md).

**Not signed.** The installers are not code-signed yet: Windows may say "Windows protected your PC" (choose More info, then Run anyway); on a Mac right-click the installer and choose Open.

**Not tried:** the Mac `.pkg` on a real Mac, OpenAI with a real key (experimental), and the interface in languages other than English.

Moly is a writing coach, not a crisis, medical or legal service. Problems and questions: Hermes_creative@proton.me or the issues page.
