## What is Moly?

A **conversational AI coaching chatbot** browser extension.

**User talks WITH Moly** to build context about a person, then gets intelligent response suggestions.

## Quick Facts

✓ **Conversational** - Users chat with Moly to build context  
✓ **Context-Aware** - Moly learns from conversation history  
✓ **Local Storage** - All data stored on user's device  
✓ **Multi-LLM** - Claude, OpenAI, or Ollama  
✓ **Compliant** - No policy violations on any platform  
✓ **Private** - No tracking, no servers  
✓ **Sellable** - Ready for Chrome Web Store  

---

## User Workflow

```
1. User opens Moly
2. Moly: "Who are you responding to?"
3. User: "Someone on Tinder"
4. Moly asks guiding questions (Socratic mode)
   OR waits for user input (Direct mode)
5. User builds context through conversation
6. User pastes incoming message
7. Moly: "Here are 3 suggestions..."
8. User copies and sends
9. Moly remembers for next time
```

## Tech Stack

- React 18 + TypeScript
- Zustand (state management)
- Tailwind CSS (styling)
- Chrome Extension API
- Claude/OpenAI/Ollama (LLM)
