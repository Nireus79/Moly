Moly Privacy Source code

Download Moly

The Moly app runs on your computer and starts with your browser. Install the extension too, then press "Check again" in Moly.

Linux

Open a terminal, paste this line and press Enter:

curl -fsSL https://nireus79.github.io/Moly/install.sh | sh

For your user only, no root. It checks the download before installing.

Mac

Open Terminal, paste this line and press Enter:

curl -fsSL https://nireus79.github.io/Moly/install.sh | sh

The beta is not code-signed; the installer handles that. If macOS still objects, choose "Open Anyway" in System Settings, Privacy & Security.

Windows

Download the installer

Run it. The beta is not signed, so Windows may say "Windows protected your PC": choose "More info", then "Run anyway".
