Fifth beta of **Moly for Android**. Setting up is easier: Moly now tells you how to get an API key and takes you to the right page.

**What is new since beta.4**
- **How to get a key.** Under the key box, Moly shows four short steps and a button for the provider you picked: **Get a Claude key** or **Get an OpenAI key**. The button opens the provider's page in your browser. It also says that a chat subscription (Claude or ChatGPT) is not an API key.
- **Manual.** The "Getting started" steps mention the new buttons.
- **Same on the desktop extension.** The key section there shows the same steps and button.

Everything else is as in beta.4. If an earlier beta is installed, this updates it in place and keeps your data (same signing key).

**Install:** download `moly-0.1.0-beta.5.apk` below on your phone and open it. Check the file against `SHA256SUMS` if you like. Step by step: [INSTALL.md](https://github.com/Nireus79/Moly/blob/master/INSTALL.md#android-beta).

**You need** an Android 7 or newer phone (64-bit) and your own Claude or OpenAI key. Moly has no server: your messages go from the phone to the provider you chose, with your key, and nowhere else.

**Not tried:** OpenAI with a real key (experimental), 32-bit phones (not included), and days of background use on phones with strict battery managers (if a reply never arrives, allow Moly to run in the background in the phone's battery settings and send a report from Settings).

Beta software: expect rough edges. Moly is a writing coach, not a crisis, medical or legal service. Problems and questions: Hermes_creative@proton.me or the issues page.
