**Moly 0.1.2 for Android.** From this version on, Moly for Android, the browser extension and the desktop app carry the same version number.

**What is new since beta.5**
- **Your language.** Questions, refusals, the "skip" message and the other texts Moly writes are now written in the language you write in, not in English. Moly also keeps one form of address (in Greek, for example, the informal singular) for the whole conversation.
- **The writing box stays usable** while Moly answers, and there is a **stop button**.
- **First-start preferences are saved.**
- **Longer messages.** The limit is now 50,000 characters. If a message is refused, Moly shows the reason.
- **Pasted conversations.** When you paste a talk between several people, Moly asks which of them is you before it advises.
- **Fewer wrong assumptions.** Moly's replies state only what you told it; a person or fact you did not mention is not added.
- **Less code, same behaviour.** Several old analysis steps that slowed replies or reset what Moly had understood were removed. The extension no longer writes message text to the browser console.

**Install:** download `moly-0.1.2.apk` below on your phone and open it. It updates an earlier beta in place and keeps your data (same signing key). Check the file against `SHA256SUMS` if you like. Step by step: [INSTALL.md](https://github.com/Nireus79/Moly/blob/master/INSTALL.md#android-beta).

**You need** an Android 7 or newer phone (64-bit) and your own Claude or OpenAI key. Moly has no server: your messages go from the phone to the provider you chose, with your key, and nowhere else.

**Not tried:** OpenAI with a real key (experimental), 32-bit phones (not included), and days of background use on phones with strict battery managers. The interface is still English only; only Moly's own writing follows your language.

Moly is a writing coach, not a crisis, medical or legal service. Problems and questions: Hermes_creative@proton.me or the issues page.
